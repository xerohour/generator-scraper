Generator Scraper

Self-hosted scrape-to-zip for public Perchance generators. Every file is downloaded as raw bytes and size-checked against the manifest — binaries arrive intact, no more corrupted PNGs, audio, or WASM in your zips.

1. Copy the file list

Drag this to your bookmarks bar: 🧲 Scrape data

  1. Open the generator’s page on perchance.org
  2. Click the Scrape data bookmark — it copies the generator’s file list
  3. Paste it in step 2 below

Why the extra step? Perchance only lets its own pages request a generator’s file list, so this page can’t fetch it directly. The bookmarklet runs on the generator’s page where it’s allowed; this page then does the downloading and zipping. If the clipboard is blocked, the bookmarklet opens a tab to copy from manually.
